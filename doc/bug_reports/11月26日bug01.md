## 详细发现

### BUG-01 · P1 · 普通键或共享映射目标的释放被吞掉

使用默认预设，先按住 F，再按住左 Command，保持左 Command 按下并松开 F，最后松开左 Command。默认规则会把左 Command 映射为左 Alt。F 的按下经 `Native(Local)` 登记，释放因需要重写修饰标志转成 `Emit`，控制器按 `Mapped(Local)` 登记。后一来源无法清除前一来源的持有状态，最终的 F Up 被过滤。纯映射也能触发同类问题，例如自定义 A→S，原生 S 和映射 A 交叠按住时，引擎只报告目标的第一次按下和最后一次释放，而控制器按不同来源处理两次事件。 [默认规则](../../crates/config/src/lib.rs#L590-L593) · [引擎按下计数](../../crates/rule-engine/src/lib.rs#L857-L903) · [引擎释放和标志重写](../../crates/rule-engine/src/lib.rs#L906-L941) · [控制器分流](../../src-tauri/src/lib.rs#L895-L921) · [输出持有状态](../../src-tauri/src/output_ownership.rs#L202-L228)

在基线临时副本中使用真实 `RuntimeController` 和只记录事件的注入替身。默认 F 场景只交付 F Down，原生持有记录仍存在。A→S 测试覆盖原生 S 先按和 A 先按两种顺序，两种都只交付 S Down。下游可能把键维持在按下状态，影响随后输入。建议在引擎和控制器之间保留同一个按下与释放来源，使修饰标志重写以及跨来源共享目标使用一致的持有状态。

### BUG-02 · P1 · macOS 13 自动粘贴调用系统尚未提供的 API

项目声明支持 macOS 13 及以上。用户选择一条历史并恢复目标应用时，适配器无条件调用 `NSApplication.yieldActivationToApplication:`，随后尝试 `NSRunningApplication.activateFromApplication:options:`。两者在 Apple AppKit SDK 中都标注从 macOS 14.0 起可用。现有的 `activateWithOptions:` 回退在第一次调用之后，macOS 13 可能抛出 `unrecognized selector` 并终止进程。建议在 macOS 13 使用旧激活 API，仅在系统支持时调用新方法，同时显式声明打包最低版本为 13.0。等价 Swift 调用以 `arm64-apple-macosx13.0` 类型检查时，两处均被报告为仅 14.0 起可用。加入版本分支后同一检查通过。未在 macOS 13 真机启动该流程。 [支持范围](../需求文档.md#L15) · [剪贴板激活调用](../../src-tauri/src/clipboard.rs#L756-L761) · [原生激活实现](../../crates/macos-adapter/src/clipboard.rs#L202-L233) · [最低系统版本配置位置](../../src-tauri/tauri.conf.json#L38-L41)

### BUG-03 · P2 · 自动粘贴可能发往错误的前台应用

剪贴板面板仅保存打开时前台应用的 Bundle ID。恢复时按 Bundle ID 查找并激活第一个运行实例，同一应用多实例时无法确认恢复的是原实例。即便实例唯一，worker 确认前台应用后还会等待 50 ms，此后只检查选择是否被取消，并全局发送 `Command+V`。用户或系统在这段时间改变焦点时，所选内容可能进入意外的应用。建议记录原运行实例，在派发前再次校验焦点，无法确认目标时取消自动粘贴。该项由代码调用链核实，未向任何真实应用发送粘贴事件。 [前台实例获取与恢复](../../crates/macos-adapter/src/clipboard.rs#L192-L225) · [目标记录](../../src-tauri/src/clipboard.rs#L68-L95) · [粘贴前检查与输出](../../src-tauri/src/clipboard.rs#L774-L810) · [前台判定条件](../../src-tauri/src/clipboard.rs#L874-L893) · [系统事件投递](../../crates/macos-adapter/src/lib.rs#L1657-L1665)

### BUG-04 · P2 · 剪贴板历史更新会改变已选条目

使用方向键选中一条历史后，后台复制会把新条目或重复条目移到列表首位。面板收到新快照时只保留并裁剪旧下标，Enter 却根据该下标读取新数组中的条目 ID。用真实 `ui/clipboard.js` 和 Node 界面替身验证，选中合成条目 ID 7 后在列表首位插入 ID 8，Enter 实际向后端提交 `select_clipboard_item(8)`。建议使用稳定 ID 跟踪选择，条目消失时清除选择。 [历史列表重排](../../crates/clipboard-core/src/lib.rs#L61-L79) · [快照应用](../../ui/clipboard.js#L33-L49) · [键盘选择](../../ui/clipboard.js#L144-L157)

### BUG-05 · P2 · 历史主文件损坏后，有效备份会被忽略和覆盖

主历史 JSON 无法解析时，加载器移走主文件并返回空历史，没有检查先前写入的 `.bak`。worker 将恢复结果视为可写。第一次成功保存以新记录建立主文件，下一次成功保存又把该主文件覆盖到 `.bak`，原先唯一可读的旧历史备份随之被替换。用真实 `ClipboardStore` 和临时目录验证，损坏主文件后活跃历史为 0 条，旧备份仍可读出 1 条。连续保存两条新记录后，旧备份条目已不存在。建议在损坏恢复分支先保全并验证现有备份，再按可辨认的保存状态决定是否恢复。其中应保留“清空历史”所表达的用户意图，避免把用户已清空的历史恢复到列表。 [损坏文件处理](../../crates/clipboard-core/src/lib.rs#L164-L186) · [备份轮换](../../crates/clipboard-core/src/lib.rs#L189-L214) · [worker 的可写状态](../../src-tauri/src/clipboard.rs#L163-L189) · [当前备份约定](../../README.md#配置与规则)

### BUG-06 · P2 · 记忆的输入源失效时会降级整个 Windows 模式

当前保持在拼音，缓存的上一个 ASCII 布局已移除，同时仍有另一个可用的 ASCII 布局。此时短按 Shift，代码优先选缓存 ID，只在缓存为空时使用可用列表里的备用布局。过期 ID 返回“目标输入源未启用”，随后本地输入读走异步错误并将整个运行时切到 `Degraded`，其他快捷键也随之停止转换。建议先用当前启用列表验证缓存 ID，再选择备用布局。普通布局不可用应由输入源功能报告，并保留其他映射。该项已核实调用链，未修改系统输入源配置。 [记忆布局的更新](../../crates/macos-adapter/src/input_source.rs#L327-L347) · [目标与备用布局选择](../../crates/macos-adapter/src/input_source.rs#L386-L408) · [异步错误](../../crates/macos-adapter/src/input_source.rs#L247-L255) · [运行时降级](../../src-tauri/src/lib.rs#L875-L882)

### BUG-07 · P2 · 剪贴板热键请求拒收后仍吞掉原按键

物理键盘或走本地兼容路径的 Deskflow 触发左 Option+V 时，剪贴板命令队列如果已满或接收端已关闭，`try_show()` 会返回 `false`。本地回调忽略结果，仍按热键锁存抑制 V 的 Down、Repeat 和 Up，用户看不到面板，目标应用也收不到这组按键。软件输入路径已有请求拒收时透传整组按键的处理。建议本地路径采用一致的失败处理，并验证按下、重复和释放始终沿同一路径结束。 [本地热键回调](../../src-tauri/src/lib.rs#L292-L302) · [剪贴板队列](../../src-tauri/src/clipboard.rs#L369-L375) · [非阻塞入队](../../src-tauri/src/clipboard.rs#L429-L431) · [软件路径的透传处理](../../src-tauri/src/software_keyboard.rs#L1132-L1155)

### BUG-08 · P2 · Windows 模式下录到的是转换后的按键

启用 Windows 模式并配置 B→N 后，在规则编辑器开始录制并按下物理 B。录制只在 WebView 监听 DOM 键盘事件。原生 Event Tap 没有收到录制状态，仍先抑制 B、注入 N。分段验证中，真实规则引擎将物理 B（`key:11`）转换为 N，真实 Node 录制器接收 N 后返回 `key:45`。建议由原生层把录制期间的原始按键交给编辑器，并在完成、取消或失焦时退出录制状态。原生投递路径通过代码核实，未用真实 WebView 录制。 [录制入口和 DOM 监听](../../ui/app.js#L243-L275) · [DOM 键码表](../../ui/rule-editor-core.js#L6-L18) · [Event Tap 处理和注入](../../src-tauri/src/lib.rs#L303-L339) · [原事件抑制](../../src-tauri/src/lib.rs#L911-L921)

### BUG-09 · P2 · 菜单栏入口没有图标或标题，模式切换标签固定

应用创建托盘时只设置菜单和事件处理器。项目锁定的 Tauri 2.12.5 和 tray-icon 0.25.1 不会从应用图标自动填充该状态项，默认图标和标题为空。正式 App 包配置为 `LSUIElement`，设置窗口关闭后会隐藏，菜单栏入口因此难以辨认。即便打开菜单，模式项始终写着“启用 Windows 模式”，而当前正在运行时实际会停用。建议明确设置菜单栏图标，并根据运行状态更新菜单项。该项核验了当前配置和锁定依赖源码，未启动正式包查看菜单栏。 [菜单与托盘](../../src-tauri/src/lib.rs#L1264-L1286) · [窗口隐藏行为](../../src-tauri/src/lib.rs#L1232-L1239) · [App 包配置](../../src-tauri/Info.plist#L4-L6) · [Tauri 应用和打包配置](../../src-tauri/tauri.conf.json#L9-L37)

### BUG-10 · P2 · 首次启动失败未显示权限或 Event Tap 错误

缺少输入监控许可时，Event Tap 创建直接返回错误。应用启动丢弃返回值，运行时仍处于默认的 `Disabled`，也没有保存错误。设置页能收到实时权限布尔值，却只在缓存权限为 `Denied` 时提示授权。未授权时可能只看到普通的暂停状态，且依赖 Event Tap 的剪贴板热键无法工作。无权限与 CoreGraphics 创建失败也无法在首次启动界面区分。建议保留启动结果并用实时权限状态区分两类问题。该项由启动调用链核实，未改动主机授权。 [Event Tap 创建](../../crates/macos-adapter/src/lib.rs#L808-L835) · [启动错误丢弃](../../src-tauri/src/lib.rs#L1254-L1263) · [运行时默认值](../../src-tauri/src/lib.rs#L609-L619) · [权限字段](../../src-tauri/src/lib.rs#L1323-L1355) · [设置页提示](../../ui/app.js#L59-L79)

### BUG-11 · P2 · 保存显示桌面快捷键会抹掉等待期间的新草稿

提交 `key:11` 后，保存按钮暂时禁用，但输入框仍可编辑。在首次保存返回前把输入改为 `key:12`，旧请求成功后无条件清除 `desktopDraftDirty`，重绘会用已保存的 `key:11` 覆盖新草稿。用真实 `ui/app.js` 和可控制响应顺序的 Node 替身验证了该行为。建议在提交时记录草稿版本，只清除该次确认的草稿，或在保存期间明确禁用编辑。 [保存期间的控件和草稿渲染](../../ui/app.js#L85-L100) · [输入与保存事件](../../ui/app.js#L212-L219)

### BUG-12 · P2 · 把滚轮配置成普通按键或鼠标按钮会缺少释放

配置导入允许纵向滚动映射为 F（`scroll:vertical` → `key:3`），也允许映射为鼠标按钮。macOS 滚轮只产生 `Motion`，引擎直接交付动作的 Down，既没有原始 Up，也没有可用于清理的引擎绑定。用真实配置导出、导入和运行时测试，连续两次纵向滚动只交付一次 F Down，停用映射后没有产生任何释放。类似地，把普通键配置成 `invert_scroll` 也能通过校验，原生层却会拒绝从键盘事件生成滚轮转换，进而造成整个模式降级。建议按触发器校验动作类型。若需要支持滚轮触发单次按键或点击，应为每次动作生成完整的按下和释放。 [配置触发器与动作校验](../../crates/config/src/lib.rs#L397-L419) · [替换动作定义](../../crates/config/src/lib.rs#L461-L495) · [滚轮原始阶段](../../crates/macos-adapter/src/lib.rs#L1143-L1159) · [引擎替换](../../crates/rule-engine/src/lib.rs#L787-L802) · [暂停清理](../../src-tauri/src/lib.rs#L667-L683) · [滚轮注入要求](../../crates/macos-adapter/src/lib.rs#L1493-L1497)
