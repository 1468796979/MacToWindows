正在读取配置…

默认开启。Windows 模式启用时，可识别的非 Deskflow 软件保留普通文字和单键输入，同时保留 Windows 快捷键转换、剪贴板与输入法切换功能。关闭后，普通按键也使用当前映射；已生成的文字始终保留内容。

适用范围

物理键盘和 Deskflow 继续使用完整项目映射；无法与物理键盘区分的输入沿用原映射。只发送文字、缺少完整按键事件的软件无法触发对应手势。部分远程文字事件无法识别为按键，对应快捷键保留原样。此开关不自动启用 Windows 模式；暂停时保持原生输入，Option+V 仍可使用。

供 shortcut:show_desktop 使用，填写与 macOS“显示桌面”设置一致的快捷键，例如 key:103。

首次使用请在“键盘 → 文本输入 → 编辑”中关闭“使用 Caps Lock 键切换到和切换自 ABC”；Caps Lock 将保留为大小写锁定，Apple Pinyin 的单独 Shift 负责中英文切换。
