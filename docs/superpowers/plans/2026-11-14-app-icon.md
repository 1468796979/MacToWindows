# MacToWindows 应用图标实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 MacToWindows 的应用图标替换为“双方键帽桥”风格，并生成 macOS 打包所需的高分辨率图标资源。

**Architecture:** 使用透明背景的 1024×1024 PNG 作为设计母版，通过 Tauri 图标生成器产出 macOS `.icns` 与多尺寸 PNG；保持应用标识符、功能代码和 UI 不变。

**Tech Stack:** ImageGen、PNG、Tauri 2、cargo-tauri。

**Spec:** `docs/superpowers/specs/2026-11-14-app-icon-design.md`

## Global Constraints

- 图标必须表达 Mac 与 Windows 键位转换。
- 图标不包含小尺寸难以辨识的文字。
- 保持 `com.mactowindows.desktop` 不变。
- 仅修改图标资源和必要的打包配置，不修改应用行为。
- macOS 图标资源需要覆盖高分辨率 Dock、Finder 和安装包场景。

## Review Focus

- 1024×1024 母版边缘清晰、透明通道正确。
- 16×16 和 32×32 缩小后仍能识别为双键帽与转换箭头。
- `.icns` 和 Tauri 生成的 PNG 资源名称、路径正确。
- Tauri release 构建能找到图标资源，不回退到默认图标。
- 应用标识符和既有权限相关配置不发生变化。

### Task 1：生成图标母版

**Files:**
- Modify: `src-tauri/icons/icon.png`
- Add: `src-tauri/icons/icon-master.png`（如 Tauri 工具链需要独立母版）

- [ ] 使用 ImageGen 生成透明背景、1024×1024 的“深蓝圆角底板 + 两个相连圆角键帽 + 白色左右转换箭头”图标。
- [ ] 检查输出尺寸、RGBA 通道、无文字、无水印，并复制最终母版到 `src-tauri/icons/`。
- [ ] 将项目使用的 `icon.png` 更新为最终母版或等价的高分辨率输出。

### Task 2：生成 Tauri/macOS 资源

**Files:**
- Modify/Create: `src-tauri/icons/*`
- Modify if required: `src-tauri/tauri.conf.json`

- [ ] 优先运行 `cargo tauri icon src-tauri/icons/icon-master.png`，生成 `.icns` 和各尺寸 PNG。
- [ ] 若 CLI 不可用，使用 macOS `sips` 与 `iconutil` 生成 `.iconset` 和 `.icns`。
- [ ] 确认 Tauri 配置能引用生成的资源，且不改变 bundle identifier。

### Task 3：验证与交付

- [ ] 运行 `cargo fmt --all -- --check`。
- [ ] 运行 `cargo test --workspace`。
- [ ] 运行 `cargo build --release --target aarch64-apple-darwin --manifest-path src-tauri/Cargo.toml`。
- [ ] 使用 `file`、`sips` 或 `iconutil` 检查最终图标资源。
- [ ] 检查 `git diff --check`、提交中文信息并推送 `origin/master`。
