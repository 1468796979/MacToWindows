# MacToWindows 应用图标设计

## 意图

为 MacToWindows 增加清晰、可缩放的 macOS 应用图标，突出“Mac 键位转换为 Windows 键位”的核心定位，并在 Dock、Finder、菜单栏和安装包中保持一致。

## 选定方向

采用“**双向键帽桥**”：两个相连的圆角键帽代表 Mac 与 Windows 键位，中间使用左右转换箭头表达映射关系。图形保持无文字、中心对称、在 16px 到 1024px 范围内可辨识。

## 视觉方案

- 主色：深蓝底、亮蓝/青色键帽、白色转换箭头。
- 形态：圆角方形底板，简化几何线条，避免细小文字和复杂阴影。
- 气质：现代、可靠、工具型，能够与现有深色 UI 协调。
- 输出：透明背景的母版图，并生成 macOS 打包需要的 PNG 图标资源。

## 实现范围

- 替换 `src-tauri/icons/icon.png`。
- 保持 `com.mactowindows.desktop` 和现有打包配置不变。
- 不修改应用功能、窗口布局或权限逻辑。
- 生成后运行图像尺寸检查、Rust workspace 测试和 macOS 构建检查。

## 备选与取舍

- `MW` 字母标志：品牌感强，但小尺寸下字母容易糊成一团。
- 剪贴板键帽：能体现新功能，但会让应用定位偏向剪贴板工具。
- 双向键帽桥：最直接表达键位转换，且不依赖文字，因此作为本次方案。
